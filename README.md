# Dynamic-Expense-Tracker
A lightweight, client-side web application that allows users to input, categorize, and track their daily financial expenses. The application calculates the total expenses in real-time and persists the data using the browser's LocalStorage.

 Features

Add Expenses: Quickly input an expense name and amount.

Real-time Calculation: The total amount updates automatically as new expenses are added or removed.

Data Persistence: Expenses are saved in the browser's LocalStorage, meaning data won't be lost upon page refresh.

Delete Functionality: Remove specific expenses with a single click.

Tech Stack

HTML5: Structure and semantics.

CSS3: Styling and responsive layout.

Vanilla JavaScript (ES6): DOM manipulation, event handling, and LocalStorage integration.

How to Run Locally

Clone this repository: git clone https://github.com/JMAGUSTIN01/expense-tracker.git

Navigate to the project folder.

Open index.html directly in any modern web browser. No server installation is required.
