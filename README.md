# Dynamic Expense Tracker
A client-side web application allowing users to input, categorize, and track daily financial expenses with real-time total calculations.

## Features
* **Real-time Tracking**: Instantly updates totals upon adding or deleting items.
* **Persistent Storage**: Utilizes browser `LocalStorage` so data is not lost on refresh.
* **Responsive UI**: Clean, mobile-friendly interface built with CSS.

## How to Run
Simply open `index.html` in any web browser. No server required.
